Methodology

One curve, fitted to real order books, read four ways. Here is how it's built, how wrong it is, and where it breaks.

The curve

cost (bps) = 10,000 × Y × σ × (Q / V) ^ δ

Q is the sale size in USD. V is yesterday's 24h volume and σ the 30-day daily volatility, both from CoinMarketCap. Y and δ are fitted. It starts from the square-root law of market impact (Almgren, Thum, Hauptmann & Li, 2005), where δ = 0.5. That law describes orders worked over a day while the book refills. Exit measures something harsher: selling everything immediately. So δ is fitted too, and the data puts it at {{ '%.3f' | format(cal.delta) }}.

Every number on the site comes from this one curve:

  • Exit cost: the curve at your size.
  • Max position: the curve solved for the size that costs {{ tol / 100 }}%.
  • Grade: max position against the scale below.
  • Manipulation cost: the size that moves the marginal price 10%, which is (1 + δ) × the average cost.

Ground truth

Every day we download the full public order books from Binance, OKX, Coinbase and Kraken for every token we rate. For each token we merge the bids from all four exchanges and walk them, as if routing one sale across all four at once, at $10k, $100k, $1M and $10M. Cost is measured against the combined mid price, so it includes the spread. Each day's inputs come from the previous day, so the model never sees the day it's tested on.

How wrong it is

Every model is scored on tokens it never saw: 5-fold cross-validation grouped by token. The baseline is the textbook square-root law. A learned model only ships if it cuts the median error by {{ ((cal.learned_margin or 0.05) * 100) | round | int }}%, a rule set before any results were in.

Limits

  • Coverage. CMC's volume counts every exchange and DEX, but our order books cover four exchanges. For thin tokens this makes the model too optimistic (see false comfort).
  • Immediate sale only. Spreading a sale over hours or days costs less than these figures.
  • Few days of data. The fit updates daily as more snapshots accumulate.
  • Not a crash predictor. Hindsight shows liquidity looked healthy before LUNA and FTT collapsed.
  • Pegged assets. Stablecoins with almost no volatility are not rated. Peg risk is a different problem.

Data & API
